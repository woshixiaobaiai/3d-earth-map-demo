# 3D 地球地图定位演示系统

类似 Google Earth 的 3D 地球地图应用，支持从太空视角搜索定位、飞行动画、城市级 3D 地图展示。

## ✨ 功能特性

### 🌍 地球模式
- 完整的 3D 地球展示
- 支持鼠标拖拽旋转
- 滚轮缩放支持
- 自动缓慢旋转
- 深色宇宙背景
- 真实光影效果

### 🔍 搜索定位
- 支持城市、地标、详细地址搜索
- 地理编码服务
- 搜索中 Loading 状态
- 搜索失败友好提示

### ✈️ 飞行动画
- 平滑的地球旋转动画
- 镜头从太空逐步推进
- 多阶段高度过渡
- 目标点发光标记
- 脉冲光圈动画效果

### 🏙️ 城市 3D 模式
- 百度地图 GL 3D 视角
- 60° 倾斜视角展示
- 道路和建筑立体感
- 地图旋转、拖拽、缩放
- 地点信息卡片展示

### 🎨 UI 设计
- 玻璃拟态风格
- 深色科技感主题
- 统一的动画过渡
- 响应式布局设计

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **3D 地球引擎**: CesiumJS
- **城市 3D 地图**: 百度地图 JavaScript API GL
- **样式方案**: CSS / 原生样式

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置百度地图 AK

编辑 `src/utils/config.ts` 文件：

```typescript
export const APP_CONFIG = {
  // 替换为您的百度地图 AK
  BAIDU_MAP_AK: 'YOUR_BAIDU_MAP_AK',

  // 可选：Cesium Ion Token（用于加载官方地形和影像）
  CESIUM_ION_TOKEN: '',

  // ... 其他配置
};
```

#### 获取百度地图 AK：

1. 访问 [百度地图开放平台](https://lbsyun.baidu.com/)
2. 注册/登录账号
3. 进入「控制台」→「应用管理」→「我的应用」
4. 创建应用，选择「浏览器端」
5. 复制生成的 AK

### 3. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000 即可查看效果。

### 4. 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

## 🎯 使用说明

### 基本操作

1. **打开页面** - 看到完整的 3D 地球，自动缓慢旋转
2. **拖拽地球** - 按住鼠标左键拖动可以旋转地球
3. **缩放** - 使用鼠标滚轮缩放视角
4. **搜索地址** - 在左上角搜索框输入地址（如："北京天安门"、"上海陆家嘴"）

### 飞行动画流程

输入地址并搜索后：

1. 地球旋转，让目标区域转到正面
2. 镜头从太空高度（10000km）逐步下降
3. 飞行到城市高度（5000m）
4. 继续下钻到街道级别（500m）
5. 淡入百度地图 3D 视角
6. 显示地点信息卡片

### 返回地球模式

点击地点信息卡片上的「返回地球」按钮：

1. 百度地图淡出
2. 镜头从城市上空拉远
3. 回到地球全景视角
4. 恢复地球自动旋转

## ⚙️ 配置说明

编辑 `src/utils/config.ts` 可自定义以下参数：

### 初始视角配置

```typescript
EARTH_INITIAL_VIEW: {
  longitude: 116.397428, // 初始经度
  latitude: 39.90923,   // 初始纬度
  height: 10000000,     // 初始高度 (米)
  heading: 0,           // 朝向角度
  pitch: -90,           // 俯仰角度
}
```

### 飞行动画配置

```typescript
FLIGHT: {
  DURATION: 4000,              // 飞行总时长 (毫秒)
  CITY_LEVEL_HEIGHT: 5000,     // 城市级别高度
  STREET_LEVEL_HEIGHT: 500,    // 街道级别高度
}
```

### 百度地图配置

```typescript
BAIDU_MAP: {
  DEFAULT_ZOOM: 18,     // 默认缩放级别
  DEFAULT_TILT: 60,     // 默认倾斜角度
  DEFAULT_HEADING: 0,   // 默认旋转角度
}
```

### 地球旋转配置

```typescript
EARTH_AUTO_ROTATE: {
  ENABLED: true,    // 是否启用自动旋转
  SPEED: 0.1,       // 旋转速度
}
```

## 🔧 坐标系统

项目支持多种坐标系统转换：

- **WGS84** - GPS 坐标，Cesium 使用
- **GCJ02** - 中国国测局坐标（火星坐标）
- **BD09** - 百度坐标

坐标转换工具位于 `src/utils/coordinateTransform.ts`。
